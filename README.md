# python-pytest-bridge

A small project for learning Git, Python and pytest by building and testing a cart total module.

## Requirements

- Python 3.12 or newer
- Git

## Set up

1. Create a virtual environment: `python -m venv .venv`
2. Activate it (see the lesson for your system).
3. Install the pinned packages: `pip install -r requirements.txt`

## Running the code

Run a script from the project folder with `python cart_app/FILE.py`.

## Lessons are tagged

Every lesson ends on a tag named `b01`, `b02` and so on. To start from the end of lesson N, check out tag `bNN`
and create a branch for your own work, for example `git switch -c my-work b05`.
